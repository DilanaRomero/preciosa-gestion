# Preciosa Gestión

Aplicación web React + Vite + Supabase para administrar inventario, productos combinados, clientes TikTok, ventas en lives, pagos, entregas y asistencia.

## Stack
- React + Vite
- Supabase PostgreSQL + Auth + RLS
- Vercel

## Variables
Configura en Vercel:
- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY

La base de datos se creó con `schema.sql` y `migration_v2.sql`.

## Desarrollo
```bash
npm install
npm run dev
```
